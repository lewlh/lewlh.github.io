# Lewlh's Blog (生产环境静态站点)

本项目是 [Lewlh 的个人博客](https://lewlh.github.io) 线上部署的静态资源托管仓库。

> [!NOTE]
> ### ⚠️ 仓库说明
> 1. 本仓库**仅存放自动生成的静态 HTML/CSS/JS 页面**，供 GitHub Pages 免费部署与公网访问。
> 2. **博客源码、Markdown 文章与日常写作位于私有仓库 [lewlh/hexo](https://github.com/lewlh/hexo)**。
> 3. 本仓库内容由 `lewlh/hexo` 的 GitHub Actions 自动构建并同步更新，**请勿直接在此仓库中修改文件**。
